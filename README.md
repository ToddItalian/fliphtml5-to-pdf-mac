**FlipHTML5 to PDF — Free One-Click macOS App**

I put together a lightweight macOS app that turns public FlipHTML5 links into clean, multi-page PDFs saved straight to your Desktop.

**Why it's nice:**
- **Zero extra installs:** Uses only built-in macOS tools (Safari + native PDFKit)—no Python, Node.js, or Homebrew needed.
- **Live progress bar:** Shows real-time page-by-page download and conversion progress.
- **Auto-cleanup:** Automatically removes temporary files once your PDF is built.

**Quick One-Time Setup:**
1. In **Safari**, go to **Settings > Advanced** and enable **Show features for web developers**, then click **Develop > Allow JavaScript from Apple Events** in the top menu bar.
2. Drag the app to your Desktop, **Right-click > Open** the first time to bypass the macOS unidentified developer prompt, paste any public FlipHTML5 link, and click **Download PDF**.

*(Note: For personal offline reading, archiving your own books, and public-domain/permitted content only.)*
